### 🚀 Technical Overview

7th-semester **Software Engineering student at Universidade de Brasília (UnB)** with practical experience building resilient web applications, automating mission-critical workflows, and enforcing QA standards.

* **Back-End & Distributed Systems:** Asynchronous pipelines, RESTful APIs, Webhooks, Redis caching, binary telemetry parsing, and SQL/NoSQL architectures (PostgreSQL, MongoDB).
* **AI & Document Automation:** Prompt engineering, LLM orchestration, structured parsing, and deterministic post-processing validation (Pydantic, JSON Schemas) within the **AI Lab (UnB)**.
* **Software Quality Assurance (QA):** Scenario mapping, white-box and black-box testing, unit/integration suites, and E2E automation utilizing Jest and Playwright.
* **DevOps & Infrastructure:** Linux administration, Docker containerization, CI/CD pipelines, backward compatibility handling, and Git workflows (PR reviews, semantic versioning).
